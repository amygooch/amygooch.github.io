# Amy Ashurst Gooch

Personal site for GitHub Pages: vita, research interests, and papers, including the 1998 master’s thesis and the 2006 dissertation.

The pages are static HTML. GitHub Pages can serve this directory as-is. `.nojekyll` is here so Pages does not run Jekyll.

## Publish

A user site is served at `https://amygooch.github.io` only when the GitHub repository is named `amygooch.github.io`.

1. Create a public repository named `amygooch.github.io`.
2. Push this directory to the `main` branch.
3. In the repository settings, set Pages to deploy from the `main` branch, folder `/`.

A repository with any other name is a project site, at `https://amygooch.github.io/<repository-name>/`.
